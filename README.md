# CompanyZ-Employee-Management

A robust, Java-based Employee Management System designed for efficient database handling, payroll tracking, and division-level reporting.

## 🚀 Project Overview
This system provides a streamlined interface for managing company personnel, ensuring data integrity through centralized models and secure database interactions.

## 🛠 Features
*   **Search**: Locate employees by Name, SSN, or unique Employee ID.
*   **Maintenance**: Efficiently update employee information in real-time.
*   **Payroll & Raises**: Execute automated batch salary increases and generate division-specific payroll reports.
*   **Data Integrity**: Built with strict Type Safety using Java Enums for Job Titles and Divisions.

## 🏗 System Architecture
The project follows a clean model-view-controller (MVC) inspired pattern:
*   **Model**: Encapsulates core entities (`Employee`, `PayrollRecord`, `Person`) and enforces data structures via `JobTitle` and `Division` enums.
*   **Repository**: Handles all MySQL communication using `PreparedStatement` for secure database interactions.

## 📋 Technology Stack
*   **Language**: Java (JDK 26)
*   **Database**: MySQL
*   **IDE**: IntelliJ IDEA
